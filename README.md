# 泰语图鉴 · Thai Atlas

学习网站：https://lingua-insight.github.io/

本仓库根目录保存可直接发布的静态网站。GitHub Pages 使用 master 分支根目录；`.nojekyll` 用于跳过 Jekyll 构建。

## 功能与内容

- 5,111 个不同泰语词头，15,944 条泰英例句；词条详情、声调转写、搭配和来源链接。
- 间隔复习、每日计划、选择题与拼写练习、错题、收藏、笔记和学习统计。
- 辅音与元音学习、声调规则与计算器、阅读课程和易混词辨析。
- 自定义词表导入、学习记录导出与恢复，以及离线缓存。

学习记录保存在使用者当前浏览器中，不提供账号云同步。清除浏览器数据或换设备前，请先导出备份。

## 资料覆盖范围

1,103 词有中文参考释义；其余 4,008 词目前提供英文释义。20 个录音文件随站发布，另有 71 个词条引用境外录音；系统泰语朗读取决于设备是否提供泰语声音。AI 辅助的释义、例句及课程尚未逐条经过母语教师审校。单词图卡主要呈现文字与声调，并未为每个词配备语义插图。详见 DATA-SOURCES.txt。
